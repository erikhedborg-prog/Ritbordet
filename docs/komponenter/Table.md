# Table

Listor av rum, poster, ritningar och material.

`<table class="list">` inuti `<div class="table-wrap">` (som scrollar i sidled på smal skärm). Rubrikrad i `label`-stil, rader åtskilda av `line`, hover `sunken`, vald rad `selected` (`accent-soft`). Koder och nummer i celler med klassen `code` (monospace, bryts inte). Siffror är tabulära. Revisionsmärke i sista kolumnen. Ingen randning; hårlinjerna räcker.
